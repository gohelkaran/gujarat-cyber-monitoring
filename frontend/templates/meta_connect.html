How to Obtain Real Meta API Credentials (Step-by-Step)
  1. Create Meta Developer Account: Go to developers.facebook.com and log in with your Facebook account.
  2. Create a Business App: Click My Apps > Create App, select app type "Business", and enter your App Name (e.g. Gujarat Cyber Monitoring).
  3. Add Instagram & Facebook Products: Under Add Products, add "Instagram Graph API" and "Facebook Login for Business".
  4. Convert Instagram to Professional Account: In the Instagram mobile app, navigate to Settings > Account Type > Switch to Professional (Business or Creator), then link it to your Facebook Page.
  5. Generate Access Token in Graph API Explorer:
    Navigate to developers.facebook.com/tools/explorer. Select your App, select your Page/User, and check the following required permissions:
    instagram_basic instagram_manage_insights pages_read_engagement pages_show_list public_profile
  6. Generate Long-Lived / System User Token: Convert the short-lived token to a 60-day token or create a System User in Meta Business Manager (business.facebook.com) for a permanent, never-expiring token.
  7. Paste Token: Paste the generated token into the configuration form above and click "Save & Connect Official Meta API"!

Common Meta Error Codes & How to Resolve Them
Error Code / Type Root Cause Immediate Remediation
Error 190 (OAuthException) Access token expired or user changed password. Re-generate token in Graph API Explorer, or create a System User in Meta Business Manager.
Error 100 (Missing Field / Scope) Missing permission scope or unsupported field. Ensure instagram_basic and pages_read_engagement are granted.
Error 10 (Permission Denied) Instagram account is Personal, not Professional. Switch account to Business/Creator in the Instagram app and connect to a Facebook Page.
Error 4 / 17 (Rate Limit) Hourly API call quota (200 requests/hr) exceeded. System automatically pauses calls and falls back to verified police news feeds.
